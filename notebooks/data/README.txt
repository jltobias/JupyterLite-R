FictionalBG.rda is an original synthetic border group for micromapST.
It contains twelve square districts and a name table generated by Chapter 08.
No packaged or external geographic boundary data is included.

Regenerate from repository root using desktop R:
  Rscript tools/install_r_extensions.R
  Rscript tools/export_border.R

The small prebuilt group lets the browser render linked micromaps without running
the V8-dependent BuildBorderGroup construction step. Place this data directory next
to the notebooks in the JupyterLite file browser. The R kernel starts in /drive.

Original data are covered by the repository's CC0 dedication. The micromapST
software itself is GPL >=2 and retains its own licensing and attribution.
